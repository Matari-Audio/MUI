# Research

Background reading behind MUI's design decisions. Each folder has its own
README or a numbered set of notes.

| folder | what it is |
|---|---|
| [`idiomatic-rust/`](idiomatic-rust/README.md) | sixteen notes on idiomatic Rust, from ownership to architecture, with the checks used to test them |
| [`mui-pattern-audit/`](mui-pattern-audit/README.md) | the same sixteen headings applied to MUI's own crates, plus `FIXES.md` and the repros |
| [`kurv-migration/`](kurv-migration/README.md) | an audit of KURV's three editor generations and the plan to rewrite its editor on current MUI (issue #8) — start at `00-migration-plan.md` |
| [`styling-inspiration/`](styling-inspiration/00-proposal.md) | how StyleX, daisyUI, Tailwind, Panda, SwiftUI and CSS geometry say things compactly, and what MUI should take — start at `00-proposal.md` |
